# 🌿 Harmony House Wellbeing Hub

A responsive, multi-portal digital wellbeing platform designed to support diverse community groups through tailored user experiences.

## 🔍 Overview

Harmony House is a front-end web system that provides a unified wellbeing hub while segmenting user journeys based on demographic needs. The platform is structured into four dedicated portals:

- 👶 Kids Hub (Under 12)
- 🧑‍🎓 Teens Hub (Between 13-25)
- 🧑 Work Life Hub (Between 25-64)
- 👵 Seniors Hub (Above 65)

Each portal is designed to deliver relevant services, events, and interactions in a way that minimises cognitive overload and improves usability.

---

## 🎯 Key Features

- **Multi-Portal Architecture**  
  Separate sub-sites tailored for different age groups while maintaining a consistent design system.

- **Responsive Design**  
  Fully responsive across desktop, tablet, and mobile devices.

- **Interactive Functionality**
  - Search across site content  
  - Event registration workflows  
  - Multi-step forms (contact, donation, event proposals)  
  - User account entry points (UI-level)

- **Consistent UI System**  
  Reusable components and styling across all hubs for scalability and maintainability.

---

## 🧠 Design Approach (HCI Focus)

The system was designed using established Human-Computer Interaction (HCI) principles:

- **Cognitive Load Theory**  
  Content is segmented into demographic-specific portals to reduce information overload.

- **Progressive Disclosure**  
  Information is revealed step-by-step to simplify navigation and decision-making.

- **Recognition Over Recall**  
  Clear visual structures and navigation patterns reduce the need for memory-based interaction.
